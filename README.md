# Посмотри в окно

Проектная работа по CSS — интерфейс для просмотра видеозаписей из окон разных городов мира.

## О проекте

Приложение загружает видеозаписи видов из окна и позволяет искать их по городу и времени суток. При клике на карточку видео в основном блоке меняется. Если доступны дополнительные карточки, появляется кнопка «Показать ещё».

## Функциональность

- Отображение карточек с видео при загрузке страницы
- Переключение видео кликом по карточке
- Поиск по названию города и времени суток
- Подгрузка дополнительных карточек
- Прелоадеры во время загрузки данных
- Обработка ошибок сети

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, логические свойства)
- JavaScript (ES6+)
- Кастомные элементы форм через псевдоэлементы
- Анимация через `@keyframes`

Клонируйте репозиторий и откройте `index.html` в браузере.
